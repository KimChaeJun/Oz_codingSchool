## 2조 Team Rules

### 1. 코어 타임
수업 종료 후 매일 15:20~16시, Zep에 모여서 진행하기


### 2. 쿠션어 사용하기
상대방을 배려해서 무슨일이 있어도 감정은 절제하고, 부드러운 언어로 대화하기
화나면 잠깐 바람쐬고오기

### 3. 적극적인 회의 참여
팀 프로젝트 과제 수행중 필요한 회의에서 마이크는 항상키고, 눈치보지않고 적극적인 의사표명하기

## 4. Git & Github Rules

- 작업은 개인 브랜치에서 진행하기
- 작업 전 `main` 브랜치의 최신 내용을 `pull`하기
- 작업 완료 후 원격 저장소에 `push`하기
- 다른 사람의 작업 내용을 임의로 수정하거나 삭제하지 않기
- 충돌이 발생하면 팀원들과 공유하고 함께 해결하기
